# Intervention Protocol

1. Observe.
2. Compare to baseline.
3. Assess declared conditions.
4. Retain alternative explanations.
5. Run a discriminating low-impact probe when practical.
6. Plan the least invasive intervention.
7. Check authority.
8. Execute externally only through an authorized adapter.
9. Re-measure the same metrics.
10. Classify recovered, unchanged, or degraded.
11. Ledger the evidence.

Operator approval is required for destructive context changes, model switching, tool disabling, persistent-memory mutation, and authority changes.
