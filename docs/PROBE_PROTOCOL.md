# Probe Protocol

A probe is a controlled observation intended to distinguish competing explanations before an intervention.

Good probes are narrow, reversible, evidence-producing, deterministic where possible, and cheap relative to the proposed intervention.

Examples include hashing recent outputs, replaying a known-good tool fixture, asking an independent challenger for unsupported claims, restating the active goal without persistent changes, and comparing a reduced read-only context.

Probe outcomes remain in the ledger even when they falsify the initial hypothesis.
